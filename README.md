# Імітаційна модель контакт-центру (курсова робота)

Бізнес-процес: **надходження виклику → черга (FIFO) → оператор → перевірка SLA**.
Модель відкалібрована за журналом `data/simulated_call_centre.csv` (51 708 викликів, 261 робочий день 2021 р.).

## Запуск

```
pip install -r requirements.txt
python main.py                      # або: python main.py файл.csv / файл.zip
```

## Файли

| Файл | Що робить |
| |
| `app/data.py` | читання CSV/ZIP, оцінка кількості операторів, інтенсивності потоку λ(t), тренд, підгонка розподілу |
| `app/sim.py` | імітаційна модель, серія прогонів з довірчими інтервалами, формула Erlang C, підбір штату, валідація |
| `app/gui.py` | вікно програми: 4 вкладки |
| `main.py` | запуск |

## Вкладки

1. **Дані** — показники журналу, 4 графіки, висновки (ідентифікація моделі).
2. **Симуляція** — параметри, запуск (F5), KPI з довірчими інтервалами, 3 графіки, порівняння з фактом і з Erlang C, збереження в Excel.
3. **Підбір штату** — мінімальна кількість операторів для цільового SLA.
4. **Валідація** — порівняння моделі з фактом по місяцях (MAPE).
